Rota Suína — Planejamento Logístico

Aplicação web desenvolvida para auxiliar no **planejamento e análise de rotas logísticas de produtores suínos**, permitindo comparar diferentes pontos de coleta/entrega e identificar possíveis combinações de integrados no mesmo trajeto.

O projeto foi desenvolvido a partir de um problema relacionado a processos logísticos do setor agropecuário, transformando uma necessidade prática em uma ferramenta web para apoio à análise de rotas.


Sobre o projeto

O Rota Suína permite analisar uma rota a partir de um ponto de saída e de um integrado principal, possibilitando adicionar outros integrados para avaliar combinações no mesmo trajeto.

A aplicação trabalha com dados de localização por **latitude e longitude**, apresenta os pontos no mapa e fornece informações para apoiar a análise da rota.

Além do planejamento de rotas, o sistema possui uma base cadastral de integrados, permitindo consultar e adicionar novos pontos utilizados nas análises.



Funcionalidades

* Planejamento de rotas a partir de um ponto de saída.
* Seleção de integrado principal.
* Adição de outros integrados para análise de combinações.
* Busca de integrados por nome.
* Consulta de integrados por cidade.
* Cadastro de novos integrados.
* Armazenamento de informações de nome, cidade, latitude e longitude.
* Cálculo de distância entre pontos.
* Definição de pontos utilizando coordenadas geográficas.
* Visualização dos pontos no mapa.
* Visualização da rota no Google Maps.
* Análise da distância da rota direta e da rota combinada.
* Identificação de integrados localizados na mesma direção do trajeto planejado.
* Interface voltada para planejamento e análise logística.

A aplicação considera como oportunidade no trajeto os integrados posicionados na mesma direção dos trechos analisados.
